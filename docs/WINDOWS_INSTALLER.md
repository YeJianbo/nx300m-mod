# NX300M MOD Windows 安装工具

适用于已刷 MFW 的 NX300M 1.15。支持首次安装 MOD、匹配环境升级、LUT 管理、日志导出和可恢复卸载。NX300 可能兼容但尚未验证。首次安装见随包的“首次安装说明.md”。

2026-11-06 r2 修正首次安装遗漏 ABI7 Session 选择标记的问题。已安装此前首装包的卡无需卸载重装：使用“检查升级”后“升级 MOD”，会补回两个选择标记及配套运行文件清单。升级只接受已知版本，先备份，回读核对 ABI7 后端后再发布重启服务标记。原厂 Reset、Still IQ 恢复和拍照仲裁沿用原实现。

## 升级

1. 相机关机，取出存储卡，使用读卡器接入 Windows。
2. 将压缩包**全部解压到电脑**，双击 `NX300M-MOD.exe`。无需安装 Python。
3. 选择正确盘符，点击“检查升级”。核对卷标和卷号后，点击“升级 MOD”。
4. 等待提示写入回读完成，再从 Windows 安全弹出存储卡，装回相机。

程序把更新前文件备份到解压目录下的 `backups`，并在完成后显示具体路径；请保留该目录。照片、LUT 和用户设置不属于本包的写入目标。若升级中断或报错，保留备份和错误信息，先不要继续操作相机。

升级只适用于与检查记录相符的卡；检查失败不等于卡损坏。r2 的安装与修复已通过隔离目录检查，并复用相同 ABI7 后端的既有 ARM VM 调用链证据；r2 在新卡上的实机预览、拍照写卡速度仍待复测。

## 卸载

点击“卸载 MOD”并核对卡号，工具把可识别的 `autoexec.sh` 和 `nx300m-mod` 移至卡内 `nx300m-mod-backup-*` 备份目录。照片和 MFW 固件不受影响。遇到其他启动脚本时停止，不自动处理未知脚本。

## 导出排错日志

插入存储卡后选择盘符，点击“导出排错日志”，选择电脑上的保存位置。程序同时在解压目录记录 `installer.log`；压缩包包括该文件、存储卡卷信息和 `nx300m-mod/logs` 下的 `.log`／`.txt`，不包含照片或完整设置。日志可能含设备、网络和电脑路径信息，请先自行检查，确认后再分享。工具不会自动上传。

## LUT 管理

点击“LUT 管理”查看卡内风格，选择“导入 .cube”，输入机内显示名称。支持标准 **sRGB 输入、sRGB 输出的 3D `.cube`**；导入会在电脑上拟合生成两张 NX300M 原生表，并添加到机内列表。请等编译完成后再弹卡。导入不会切换当前风格；请回相机菜单选择。原始 `.cube` 和导入前的列表备份在电脑的 `backups`。不支持 DCP、XMP、1D shaper 或 Log 色彩空间直接导入，转换效果尚需实拍确认。
