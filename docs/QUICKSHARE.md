# 相机 Quick Share

相机端分享使用 rquickshare 的协议核心，提供设备发现、PIN 确认、加密发送、进度和取消。相册集成可以将所选文件交给分享面板，RAW 与 JPEG 可选择发送格式。

## 网络

当前实现通过已有 IP 网络发现和连接设备。蓝牙发现与 Wi-Fi Direct 自动建链还需要实现；因此相机和接收端需要先具备可互通的网络。

## 使用与验证

在支持的相册分享入口选择照片和接收设备，确认双方显示的 PIN，再等待接收端确认。进度达到 100% 表示发送端已写出数据，完成状态还需要协议确认。

ARM/QEMU 的协议程序已向 Google Nearby 手机发送测试文件，相册入口、文件交接和返回在原厂程序模拟环境中测试过。实体 NX300M 从相册向手机发送照片的完整链路仍需验证。

## 代码与构建

协议代码位于 `mod/quickshare`，相册面板与构建脚本分别位于 `mod/metol` 和 `tools/build_gallery_share.py`。组件来源及许可见 [第三方组件](../THIRD_PARTY.md)；相机端服务接口见 [遥控与相册](REMOTE.md)。
