# 当前进展

当前源码包含相机端 Mod、NXConnect **0.20.33 / 81** 和 ARM 模拟开发环境。相机端本次收尾聚焦预览接入、菜单恢复与独立关闭预览。

## 相机端改动

| 模块 | 当前实现 |
| --- | --- |
| RAM LUT | 挂接 LUT 专属 Update 虚函数表入口与 `ipcs_3d_lut` GOT 入口；原厂函数负责写入 ISP |
| LUT 强度与恢复 | 0–100% 表数据混合；0% 原始指针透传；选择保存到 SD 卡；「关」停止预览并恢复成片原厂指针 |
| LUT 编译器 | cube 重采样为三路 9³、10 bit、4380 字节 D4 表；生成直接表和原厂组合表 |
| LUT 实时预览 | 普通取景插入 SmartFilter 节点，经 IPCS YCC→YCC 应用 9³ LUT；共用照片选择，支持强度、预览单独关闭及 Session 引用复用 |
| 配方与设置 | ISO 步长、ISO 扩展、Auto ISO 上限、快门上限、拨盘锁、原厂画面参数、RGB 和配方批次接口 |
| 媒体服务 | RAW＋JPEG 配对、内嵌缩略图及大预览、原文件下载和相册分享交接 |
| Quick Share | rquickshare ARM CLI、发现、PIN、加密发送、进度、取消和安全断开确认 |
| 服务运行 | SD 入口、RAM 资源运行、单实例管理、启停、运行状态及诊断采集 |
| 菜单与快捷键 | 正常 MOD 主菜单、短按 Custom 选 LUT、长按打开菜单；调试集中到子页，打开菜单保留预览，后台等待不空转 |
| 手动镜头 | 无镜头无线准入 RAM 补丁；电子镜头状态和 Lens Shading／Color Shading 更新链探针 |

## 验证进展

- NXConnect 源码为 0.20.33 / 81；本轮未修改或重新构建 App。
- 相册缩略图与照片传输已有实体相机使用反馈。
- RAM LUT 加载器完成 ARM VM 两种表来源、0／50／100% 强度、调用线程与顺序、重复加载和恢复检查。
- SmartFilter 预览已有黑白、彩色和成片 LUT 的实机使用反馈。当前修复补接 `changeStopCallbackProcess → state20 → 原厂内存匹配 → changeRestartProcess`；模拟执行原厂 ARM 代码，物理设备边界使用替身。
- 菜单检查覆盖键盘与触屏选 LUT、确认后提交、后台等待、关闭后保留选择，以及主菜单与诊断页导航。只关闭取景时保留照片选择与 Still Hook；停止后换照片风格不自动重开预览。
- Quick Share 核心完成 ARM 加密回环及 Google/Nearby 手机收件验证，相册分享入口已集成。
- 模拟环境支持原厂 ARM 用户态执行、LCD／OSD 合成、照片回放、硬件事件输入及独立模块探针。

## 接下来做什么

1. **预览切换复测**：确认首次开启及换风格不再依赖拍照或相册；确认只关闭取景后，照片仍使用所选 LUT。随后测连续拍照、RAW＋JPEG 和休眠恢复。步骤见 [机身检查](LUT_ON_CAMERA_TEST.md)。
2. **遥控**：修复 RVF 按快门后断链，确认遥控拍摄格式与 RAW＋JPEG 行为。
3. **LUT 上传**：接通手机导入 LUT 到相机的上传、编译和安装接口。
4. **连接**：处理 WLAN 自动连接的保活与重连；实现 BLE 发现和 Wi-Fi Direct 建链。
5. **性能与色彩**：测 Session 复用版本的 LCD 有效帧率、切换延迟和功耗，继续校准预览与成片的颜色域。
6. **手动镜头**：完成泛绿校正链定位、可回滚 RAM 修复和原厂电子镜头兼容验证。

成片 LUT 的原生颜色坐标、前后变换和实拍校色继续单独验证。App 中固件与安装包操作目前为本地读取检查，步骤见各专项文档。
