# 2026-11-11 闲时修复验收与收尾

最终结果：补修四处缺陷后，本轮离线验收通过。全程在电脑和隔离 ARM 环境完成，没有刷机、写卡或改动硬件预览/拍照路径。

## 查实并修复的问题

1. **关闭 LUT 误报未保存**：Off 的输入结构中强度是零，读回规范化为 100；旧比较把无关字段差异当成失败。改为 Off 仅验证 Off 语义。真实引擎关闭动作现在无保存警告。
2. **旧槽恢复表被回收**：原回收器只保护当前最高有效槽。受控复现中旧表被删，再损坏最新槽时 boot 返回 5。现在保护两个有效槽、两种旧格式记录、RAM 当前选择及刚生成目录；同一夹具中旧表保留、boot 返回 0。
3. **异常缓存目录被误删**：原代码只检查名称前缀。现在仅回收 `nx-tune-` 加 16 位小写十六进制的生成目录，异常名称保留并上报；成员删除绑定已打开的目录描述符，避免后续路径被替换时越界删除。
4. **引擎微调保存失败**：`nx_tune_regular_fd()` 使用的 stat 结构与大文件引擎 ABI 不一致。改用 stat64 家族，兼容现有 UI 和引擎构建配置；成功 apply 中的微调保存警告已消失。
