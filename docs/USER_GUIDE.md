# NX300M MOD 使用指南

目前按 Samsung NX300M、原厂 1.15、已经具备 SD 卡 `autoexec.sh` 执行能力的 MFW 环境开发验证，本版为测试版。NX300 可能兼容，但尚未验证；不保证 NX300、NX500 或其他固件版本适用。仅复制文件不会给未安装 MFW 的相机增加启动能力。

本项目非三星官方项目。测试版可能出现卡顿、拍摄中断、异常退出或文件损坏；先备份照片和原卡文件，重要拍摄前完成基本验证。第三方代码和素材沿用各自许可证，风格数据的格式转换不代表获得再分发授权。详见 [使用风险与版权说明](RISKS_AND_RIGHTS.md)。

## 下载与更新

从 [GitHub Releases](https://github.com/YeJianbo/nx300m-mod/releases) 下载。每个附件的适用范围以该次发布说明为准；源码 ZIP 不能直接复制到卡上运行。

本次提供**菜单与预览控制升级包**，更新现有匹配环境中的菜单程序、面板脚本和预览身份扫描启动器，包含读卡器更新工具。它不是完整首装包，不安装 MFW，不安装缺失的 LUT/预览后端，也不更改 Wi-Fi。已经使用开发测试卡的用户可按以下步骤升级：

1. 关机，等写卡灯熄灭，取出 SD 卡接读卡器。先备份照片、根目录 `autoexec.sh` 和整个 `nx300m-mod` 文件夹。
2. 把升级 ZIP 解压到电脑目录，不能直接覆盖 SD 卡。电脑需要 Python 3.10 或更新版本；本项目开发环境采用 Conda。
3. 在解压目录打开终端，先检查。以下用 `H:` 举例，务必替换为实际卡盘符：

   ```powershell
   python update_card.py --card H:/
   ```

4. 显示兼容且检查通过后执行写入：

   ```powershell
   python update_card.py --card H:/ --apply
   ```

   工具将被替换的菜单、控制文件和重启标记备份到电脑上的 `backups/`，写入后回读检查。它保留照片、已有风格库、`.state` 和启动脚本。若提示版本不匹配，停止升级，保留原卡；不要绕过检查强行覆盖。
5. 安全弹出卡，装回关机的相机，开机。更新含服务重启标记，供现有 RAM 启动链处理。先确认普通取景、菜单开关及拍照正常。

本包要求卡上已有匹配的 Session 预览、Still LUT 和 RAM 服务。新装环境需自行准备本机 1.15 固件及 SDK 构建，见 [安装与启动](INSTALL.md)；本仓库不分发三星固件、字体、标定表或 Adobe 风格数据。

## 打开菜单

普通取景时，**长按 Custom 打开 MOD 主菜单**。短按 Custom 优先轮换收藏，未设置收藏时轮换常用风格。Fn 用于 LUT 面板内部切换列表与微调。

主菜单有五个入口：LUT 滤镜、镜头管理、曝光增强、手机连接、系统设置。左右或转盘选择，OK 进入，MENU 返回；触摸按钮也可进入。标为“不可用”的项目尚未接入或未完成验证。

## 选择 LUT

1. 进入“LUT 滤镜”，在顶部分类中筛选风格；分类可翻页并记住最后位置。Windows 工具的“LUT 工作台”可新建自定义分组并把一款风格加入多个分组，保存后这些分组会出现在机内顶部分类栏。公开源码只附自制 Hard Mono，开发卡上的其他风格沿用原有库。
2. 右侧列表可用方向键、转盘或触摸快速选中。**浏览不改变机身效果**，按 OK 或顶部“保存”才提交。
   上下键逐项移动；只有列表第一项再按上才进入顶部分组。分组中左右键或转盘切组，下键或 OK 回列表；此时 OK 不会直接保存退出。
3. 点顶部 **“保存”**，画面显示“正在应用”，后台成功后直接回到取景器；失败会留在面板。它同时完成保存和应用，不再另设“应用取景”。
4. OK 与“保存”相同；Fn 从微调保存并回到风格列表时保持面板打开，方便继续选择。

应用过程无需半按快门确认。半按仍保留立即收起面板、优先让原厂对焦和拍照的操作。应用动画只覆盖菜单切换过程，不暂停传感器；动画结束不等于已经通过 LCD 像素读回确认颜色。

### 三种容易混淆的状态

| 操作 | 取景 | JPEG 照片 |
| --- | --- | --- |
| LUT 开，实时预览开 | 请求显示 LUT 效果 | 使用选定 LUT |
| LUT 开，实时预览关 | 原厂取景 | 仍使用选定 LUT |
| 红色“关闭 LUT” | 关闭 MOD LUT 预览 | 恢复原厂 LUT 路径 |

强度 0% 也不是完全关闭 MOD。需要原厂拍摄行为时用红色“关闭 LUT”。本项目不修改 RAW Bayer 数据；机内 JPEG、嵌入式预览和相册显示不能代替 RAW 内容核验。

## 微调与保存

按 **Fn** 或触摸“微调”，右侧变为八行参数。上下换参数，左右或转盘调值，也可触摸滑动。

| 参数 | 范围 | 含义 |
| --- | --- | --- |
| 亮度 | −10～+10 | LUT 输出亮度调整，不是曝光 EV |
| 对比度 | −10～+10 | 明暗反差 |
| 饱和度 | −10～+10 | 颜色浓淡；黑白表禁用 |
| 色温 | −10～+10 | 冷暖倾向，不更改原厂白平衡 |
| 色调 | −10～+10 | 绿—洋红倾向 |
| 阴影 | −10～+10 | 暗部层次 |
| 高光 | −10～+10 | 亮部层次 |
| 强度 | 0～100% | 风格应用比例，转盘每次 5% |

七项微调以中线为零点，向左表示负值，向右表示正值。黑白 LUT 可通过色温和色调做着色，饱和度无效。

- **Fn 再按一次**：保存并回到列表，面板保持打开。
- **OK／保存**：提交并保存，成功后回到原厂取景器。
- **重置当前**：仅将当前风格的七项调整归零、强度恢复 100%，再保存生效。
- **MENU**：返回；有修改时选择保存、放弃或继续编辑。
- **半按快门**：立即退出并让路，尚未提交的本地调整会放弃；已经运行的提交仍须安全结束。

每款风格单独保存调整，收藏单独保存。调整数值时仅更新菜单参考图，不逐键重编译机身 LUT；确认时才生成或复用缓存。卡需可写；显示保存失败时不要假定重启后仍会保留。

若库内有“原图微调”，可不套胶片风格，仅保存亮度等调整。它依然使用 MOD LUT 链，与“关闭 LUT”不同。该预设依赖用户本机生成的原厂组合表，公开菜单升级包不附带它。

## 参考图与实时预览

左侧是内置参考样图，**不是当前镜头画面**。点按在人像、风景、夜景间切换，长按看原图，松开恢复效果。它用于比较方向和强度，不能证明 LCD/JPEG 已完成校色。

“实时预览”按钮控制真正的取景 LUT，开关会保存；开机服务会尝试恢复上次选择和预览偏好。恢复失败不会无限重试。实体开机首帧、快速连续切换及预览与成片颜色一致性仍需实机验证。

## 其他功能入口

| 入口 | 当前使用范围 |
| --- | --- |
| 镜头管理 | 选择卡上已有镜头预设、查看记录；不代表机内 EXIF 已自动写入 |
| 曝光增强 | 查看已接入的控制状态；不可用项不执行操作 |
| 手机连接 | 复用现有 Wi-Fi 和 NXConnect 服务；连接成功后可访问相册、下载和已有遥控功能 |
| 系统设置 | 已接入的配置、模块状态及调试入口 |

A/P 完整快门范围、Auto ISO 25600、物理模式拨盘锁、手动镜头泛绿修复、NFC 配对等，各自的实现与实机验证进度不同。不能因菜单有入口就视为全部可用；以页面实际状态和 [交付状态](DELIVERY.md) 为准。

手机先连接相机正在提供的 Wi-Fi，再在 NXConnect 查找相机或填地址。MOD 服务常用端口为 `8781`，某些原厂入口为 `80`，App 会探测。只打开手机 App 不会自动让相机建立热点；原厂 Remote Viewfinder 与普通机身取景模式也不是同一模式。

## 停用、回退与排错

| 现象 | 操作 |
| --- | --- |
| 菜单没有出现 | 确认型号、1.15、MFW 和原来的启动脚本仍在；普通取景下长按 Custom，检查卡写保护 |
| 应用失败 | 面板保留草稿，可重试；不要反复快速提交。先关闭 LUT，确认原厂拍照正常 |
| JPEG 有效果但取景没有 | 确认“实时预览”开关；只关闭预览会保留照片 LUT |
| 颜色仍是上一款 | 等当前提交结束；按“保存”重新提交当前选择，检查最终照片。若仍复现，保留日志并回退，不用拍照刷新作为正常操作 |
| 保存失败 | 检查剩余空间、写保护及文件系统；未保存设置可能只在本次运行有效 |
| 新菜单不合适 | 关机后用读卡器运行下方回退命令，恢复更新前文件 |

在升级包目录执行（路径替换为写卡时输出的实际备份目录）：

```powershell
python update_card.py --card H:/ --restore backups/实际备份目录 --apply
```

完全停用：关机取卡，在 `nx300m-mod` 下建立**无扩展名的空文件 `DISABLED`**，装回开机。它阻止服务下次启动，不会停止已经运行的进程；若休眠快照仍恢复旧进程，关机等写卡结束后卸电池再上电。移除标记才恢复服务。需要回到更新前状态时，优先还原完整备份。

日志通常位于卡上 `nx300m-mod/logs/`；调试页可导出预览诊断。遇到卡死先尝试正常关机，等待写卡结束再取卡保存日志，避免在写入照片时拔电池。

## 验证范围

菜单、滚轮、触摸注入、保存和失败恢复使用原厂 ARM 程序环境检查。保存退出逻辑要求后台任务结束前面板不退出，失败后保留面板。Session 生命周期既有回归保留 Open/Close 配对、原厂 Reset/IQ 恢复和拍照让路。

这些是模拟器与软件逻辑检查，不能代替实体相机的 LCD 有效 FPS、首次生效时机、RAW＋JPEG 连拍、休眠恢复、功耗及校色。首次升级后最少检查：菜单开关 → Mono 保存并回取景 → 拍一张 JPEG → 关闭预览但保留 JPEG LUT → 关闭 LUT 恢复彩色 → 重启检查偏好。
