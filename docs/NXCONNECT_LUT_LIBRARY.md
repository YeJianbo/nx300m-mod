# NXConnect 手机 LUT 库

入口为「Mod 与固件 → LUT 库」，未连接相机时也能打开。连接后也可从「相机设置 → LUT 库」进入。原有色彩设置面板提供「管理 LUT 库」入口。

## 手机

- 用系统文件选择器批量导入 `.cube`，复制到应用内部存储，后续不依赖原文件的位置或授权。
- 校验 3D 网格、有限 RGB 数值、完整节点数量及 `DOMAIN_MIN/MAX`；支持 2–129 网格、最大 64 MB。1D LUT 和带 1D shaper 的文件暂不支持。
- 条目菜单支持重命名、上移、下移、查看信息、导出和删除；页顶还可按名称或最近导入排序。
- 原始 `.cube` 内容保持不变；重命名只修改库内显示名称。导出使用系统「保存到」窗口。
- 目录和顺序通过 AtomicFile 保存。移除手机条目不会操作相机卡。

`.cube` 不足以证明颜色空间和 ISP 编码兼容；本轮只保存及管理源文件，没有在手机上执行原生 D4 编译或校色。

## 相机

读取现有 `/api/v1/looks`，通过 `looks/select` 确认选择和可选的 0–100 强度，通过 `looks/stock` 恢复原厂色彩。连接身份、可写状态和接口回读继续使用已有协议层检查；滑动强度不连续发送请求。

界面区分请求已暂存、交给相机成像链和恢复原厂，不把接口转发认作照片颜色已验证。连接更换后清除旧相机状态，重新读取。

当前相机服务没有 LUT 文件上传、重命名、删除和排序接口。因此手机导入条目留在「手机」，不会被标为「已在相机」，也不提供无效的上传操作。

## 最小手机检查

1. 未连接时打开 LUT 库，导入两份有效 `.cube` 及一份节点不完整的文件；预期前两份入库，错误文件显示原因。
2. 重命名、调整顺序、退出重进，确认名称与顺序保留；导出文件应与导入源内容相同。
3. 在「手机」删除一项，确认相机卡清单不变。连接已启用 LUT 的相机后，进入「相机」选择 Hard Mono、确认强度，再恢复原厂；成片效果需要实机拍摄确认。
