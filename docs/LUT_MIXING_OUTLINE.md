# LUT 混合与新风格生成大纲

日期：2026-11-07。状态：Windows 客户端与 NXConnect 已实现；安卓模拟器创建、保存、重启和编辑回读通过，实体相机待验收。

## 1. 目标与入口

从现有 LUT 中选择两款，调整比例、查看参考照片，命名并保存为新的独立 LUT。新条目可以继续编辑配方、收藏、导出和安装到相机。

计算和管理放在电脑端 LUT 管理器与 NXConnect；相机只加载生成后的普通 LUT，继续使用已有选择、预览和拍摄流程。两端共用 `linear-srgb-output-v1` 配方格式，已用固定样例验证生成的相机表逐字节一致。

示例：选择「CC」和「海盐晴蓝」→ 调成 70:30 → 对比照片 → 命名「晴蓝纪实」→ 保存到「自制」→ 按需安装到相机。

## 2. 混合方式

### 首版：按比例融合

同一输入颜色分别经过 A、B 两款风格，再混合两个输出：

`M(x) = (1 - t) × A(x) + t × B(x)`

- 比例滑块显示 `A 70% / B 30%`；两者合计 100%。
- 滑块最左为纯 A，最右为纯 B，中间为各 50%。
- A 或 B 可以选择「原图」，用于生成减弱版风格。
- 首版最多两款，界面不增加多层堆栈。

默认在共同的、明确声明的 sRGB 编码输出域进行数值混合。这是风格插值规则，不称为光照能量混合。算法和颜色域写入配方版本，后续调整算法不能悄悄改变旧配方。

### 后续：顺序叠加

`M(x) = B(A(x))`

先经过 A，再经过 B；交换顺序会改变结果。它与按比例融合分开命名、单独提供入口。顺序叠加更容易累积对比度、色偏和裁剪，不作为首版默认操作。

“保留 A 的色彩、只取 B 的对比度”涉及风格分解，普通 LUT 混合没有这种保证；如要提供，应另设有明确定义的功能。

## 3. 编辑界面与保存行为

延续现有 LUT 管理入口，新增「创建混合风格」：

1. 顶部选择 A、B，提供交换按钮和各自的分类／搜索。
2. 中部展示参考照片，支持原图对比；可切换人像、风景、夜景，也可选本地照片。
3. 下方用大滑块调整比例，旁边直接显示双方百分比。
4. 底部提供「保存新风格」「导出」「取消」；安装到相机是单独动作。

拖动时立即更新数值，合并计算请求，只显示最新结果；不在每个触摸事件中编译机内表或向相机发送命令。单张参考图预览与整张 LUT 编译分开调度。

保存新风格留在管理器中，不自动切换相机当前风格。未保存配方保留草稿；退出有修改时提供保存、放弃、继续编辑。既有源 LUT 不被覆盖。

已有亮度、对比度、饱和度、色温、色调、阴影、高光微调可以继续作用于新风格。首版先完成混合本身；如增加“把已保存微调一起混合”，需明确选择输入版本和运算顺序，不自动混入机身未保存草稿。

## 4. 新风格的数据与生成链路

保存两类内容：

- **可编辑配方**：源风格 ID 和内容版本、混合比例、模式、工作颜色域、算法版本、名称及来源记录。保留所用源 master 的本地快照，使源库更新或移除后仍能重建。
- **独立成品**：`source.cube`、`look.json`、参考缩略图及相机所需编译表。相机运行时不依赖 A、B 目录，也不需要解析配方。

建议链路：

`读取源 master → 校验共同颜色域 → 在统一 33³ 网格采样 A/B → 浮点融合 → 保存新 master → 复用现有编译器 → 安装普通 LUT`

实现时复用已有的 `tools/look_library.py` 和 `tools/cube_to_d4.py`。当前相机表为 9³、10 位、4,380 字节；优先从高精度源生成新 master，再统一编译，不连续混合、量化多次。两端保存时使用 `round` 编译，以控制手机端等待时间，并在 metadata 中明确记录编译方法。

对于适用原厂组合表的路径，从同一个新 master 分别生成 `table.d4lut` 和 `table-stock3d.d4lut`，沿用现有发布一致性检查，避免把已经组合过的表再次套原厂基表。

首版输入选择器只开放颜色域已明确兼容的 master。仅有机内二进制表、未知颜色域或需要 Log/shaper 转换的素材，先显示具体原因；不能仅凭 `.cube` 后缀视为 sRGB。

预览至少区分“master 效果”和“机内表近似”。9³ 编译存在表达误差，参考照片的效果不直接当作实体 LCD/JPEG 一致性证明。预览、导出与相机执行的强度／微调顺序需明确，已烘焙的调整不能重复应用。

## 5. 性能与库管理

- 同一张参考照片的 A、B 结果可缓存；只改比例时直接融合缓存结果。
- 完整编译安排在保存或安装时，后台执行并显示实际进度。
- 列表只加载名称、分类和缩略图，打开编辑器才加载所需 master。
- 配方、源快照与已保存成品属于持久数据；中间预览和编译缓存才按容量回收。
- 新条目放入「自制」，可收藏和改名，默认不塞入每张卡的安装清单。
- 成品可独立导出 `.cube` 和现有相机风格包；需要继续编辑时再附带配方与源快照。来源和现有发布许可信息随条目保留。

## 6. 开发顺序

| 阶段 | 交付 |
| --- | --- |
| 1：混合核心 | 两款兼容 master、比例融合、33³ 新 master、复用机内编译、配方保存与重建 |
| 2：电脑图形入口 | 选 A/B、参考预览、比例拖动、命名、另存、导出和安装 |
| 3：NXConnect | 使用同一配方规范接入手机创建和管理，明确计算实现与离线能力，不依赖相机常驻编译服务 |
| 4：可选扩展 | 输入包含已保存微调、顺序叠加、更多源风格；按实际需要逐项增加 |

## 7. 最小验收

先构建受影响工具。针对新算法验证：0%/100% 与 A/B 对应；交换 A/B 并反转比例应等价；同源混合同源应保持结果。浮点 master 按数值容差比较，机内表按量化误差比较。

保存后关闭、重开，配方和成品保持一致；源库条目更新或移除后，快照仍可重建。连续拖动只显示最新结果，取消不安装或改变当前相机选择。

用一款生成的新 LUT 做最小实机验收：选择、预览、拍照及关闭沿用现有流程；与普通 LUT 对照检查是否引入额外加载、预览或拍摄耗时。硬件路径不新增逐帧混合，但最终性能仍以这次实测为准。
