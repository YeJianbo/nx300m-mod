### SAVE-SAME 的耐久性要求

内容相同不等于此前已同步成功。首次发现同值记录、上次返回耐久未确认、目录同步失败或进程重启后的情况，应完成现有契约所需的同步，再认定已保存。若使用进程内已确认记录，必须绑定根目录、具体槽身份及内容，检测外部替换/修改后失效；不在卡上新增“已确认”标记来代替同步。

保留双槽回退与旧格式迁移。只省去可证明重复的写入/代数增加；失败时仍保留草稿和同值重试。测试分别统计 write/fsync 次数，不以删除 fsync 获得提速。

### LOOK-CACHE 的一致性要求

草稿与已保存预设分开缓存，LRU 淘汰不得保存或丢弃草稿。外部 App/CLI 更新需按实际文件身份/版本刷新；表文件同路径替换、缺失、读取失败不能继续伪报有效。不能只用 LUT 名称作为永久命中条件。

优先缓存原始表，继续复用当前款微调结果与参考图缓存，避免每款复制整张参考图。记录缓存增量 RSS 和读取次数，收益不足则缩小范围。

### HOOK-STATUS 的状态要求

`nx_lut_ram_update()` 经 `selection()` 每次重置 `forwarded`，已有历史报告曾读错这点。不要追加无用途复位。无变化判断应基于 generation、启用状态、强度、组合分支、结果等业务字段；累计诊断计数单独按需报告，避免计数每次增加令去重永远不命中。

原 Hook 使用多个并发上下文，状态去重不能让旧上下文覆盖新状态、跳过错误通知或在帧路径引入等待。上下文内连续重复、跨上下文、失败恢复和状态文件删除分别验证。原厂程序离线环境中自然调用频率无法得到时，报告实际夹具频率与未测条件；本项可交付测量结论，不凭合成高频测试自动启用优化。

## 2. 25Hz 调度与交互要求

当前源码连续输入采用约 66ms 绘制门限，主事件批次与 `next_frame` 另有约 33ms 调度；单改 66→40 会受另一时钟量化影响。先按实际事件循环统一计算下一次输入、绘制、子进程和参考图到期时间，保持无输入时等待。

推荐方向：

1. 数值、滑块和焦点目标 25Hz，40ms 一次；离散按键、点击、Fn、OK、MENU 优先响应。
2. 每个输入均进入现有参数/导航状态机；合并的是绘制与参考图计算请求，只执行最新版本。转盘跨项、正反方向交替、点击和释放事件不能按“取最后一个事件”粗暴丢弃。
3. 将数值绘制与参考图重计算解耦。参考图争取同达 25Hz；计算超预算时合并到 12–15Hz，屏幕保留上一张完整图，数值照常更新，停止后补绘最新效果。所有相机应用仍由明确确认触发，不在每个滑块事件重新编译或提交 IPCS。
4. 先复用现有单 UI 线程、dirty/revision 和脏区域机制。若主线程参考图单次计算仍超过预算，先优化计算或做有界分段；分段结果写私有候选缓冲，完整且版本仍匹配才发布，避免撕裂和旧图覆盖新图。不要先增加常驻线程/进程池。
5. 绘制门限从实际开始/结束时刻合理推进，持续输入不会无限延后；有待显示状态时才安排唤醒。完成子进程、重置、换场景、原图按住/松开都刷新对应参考版本。

### 同条件离线对照

复用现有私有 ARM X11 探针，使用相同 VM、CPU/核数/内存、输入序列、菜单与图片素材，对照当前基线和候选的 15/20/25Hz。轮换测试顺序，按输入活跃窗口统计实际显示频率，不能用循环唤醒数冒充帧率。

必测输入：

- 连续转盘正转/反转、快速交替，跨参数和 LUT 列表导航。
- 触控拖动后释放、触控点按与转盘混合，单次方向键。
- 八项参数、强度 0/100、中性与正负微调、黑白参数禁用状态。
- 参考场景切换、原图按住/松开、风格快速切换。
- 连续操作中 Fn 保存留页、OK 确认、MENU 返回；保持当前请求快照与草稿语义。

每组记录：

- 注入/实际消费的输入数、最终参数与选中项、中间状态绘制次数。
- 输入至数值显示的 P50/P95/P99、参考图更新间隔与端到端延迟。
- 输入停止到最终数值及最终参考图显示的时间，区分两个时刻。
- 纯 UI 绘制与参考计算分别计时的 P50/P95/P99、进程 CPU 累计耗时、RSS、空闲唤醒数。
- 相同状态截图逐像素对照；固定点/整数舍入及原图素材保持一致。

25Hz 的活动帧预算为 40ms；数值显示链路应具备与预算相符的 P95，而参考图低频退让必须单列实际频率。停止输入后，数值目标在下一次 40ms 调度内更新，最终参考图目标 100ms 内完成；超过目标如实记录并查出耗时阶段。门限从生产代码实际消费最后一次输入起计算，另报注入排队延迟，避免隐藏积压。

最终采用在输入延迟、终值完整及 CPU 占用上表现合适的一档；25Hz 未通过就保留更好的 20/15Hz，并明确未达成项。不得为了提高平均帧率减少输入处理、遗漏中间绘制、长期满核或只在停止后刷新。
