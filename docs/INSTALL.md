# 安装与启动

已有 MFW 的 NX300M 可以通过 SD 卡根目录的 `autoexec.sh` 启动服务。相机端文件位于卡上的 `nx300m-mod` 目录；服务将运行资源复制到 RAM，再启动遥控和相册服务。

## 准备 SD 卡

1. 备份照片，以及卡上已有的 `autoexec.sh` 和 Mod 文件。
2. 使用当前构建生成的 SD 包，将包内 `nx300m-mod` 目录和对应的 `autoexec.sh` 放到卡根目录。构建方法见 [MFW 服务](MFW_SERVICES.md)。
3. 安全弹出卡，装回已关机的相机，然后开机。手机连接相机的无线网络后，在 NXConnect 中查找相机或输入地址连接。

脚本入口取决于相机已安装的 MFW；仅复制文件不会给原厂固件添加脚本执行能力。安装包中的具体文件和启用的模块以构建清单为准。

## 关闭与恢复

关机后取出卡，用读卡器移走根目录的 `autoexec.sh`，可以阻止后续通过该入口自动启动。也可以在 `nx300m-mod` 下创建空文件 `DISABLED`，阻止该服务下一次启动。已有机身 shell 时，可运行：

```sh
/bin/sh /mnt/mmc/nx300m-mod/stop.sh
```

停用标记不会停止已经运行的进程；休眠快照的恢复行为还需要实机确认。遇到无法关机或存储异常时，先断电、取卡并备份，再检查卡上的入口和文件系统。

## 模块与刷机

服务启动和机内模块加载是两个步骤。曝光、配方和 LUT 等功能需要相应模块加载；分组说明见 [启动配置](LAUNCH_PROFILES.md)。App 的固件页面目前用于检查文件格式。

固件封装、启动路径和救援研究见 [部署与恢复](RECOVERY_AND_DEPLOYMENT.md)。NX300M 的刷写及救援流程尚未完成实体机验证。
