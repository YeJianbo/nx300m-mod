# S2 连续 LUT 取景候选（ABI4）

本候选恢复连续黑白和当前 LUT 入口，目标是在原厂智能滤镜关闭、RAW／RAW+JPEG 下直接看到 LUT 取景。它不是单位表单帧探针包；底层 loader/blob、拍摄锁、Reset／Still IQ 恢复保持原实现，不启用硬件参数复用。

11月2日实机反馈：进入回放再返回取景后，黑白已持续更新；开启时卡顿，软停后恢复流畅。当前性能采样候选及步骤见 [连续黑白短采样](SMARTFILTER_LIVE_TIMING.md)。

## 机身测试

安装需先备份，禁止在写卡灯亮时拔卡或断电。当前只交付本地候选，部署另行授权。

- 正常开机，进入普通 P/A/S/M 取景，原厂智能滤镜保持关闭，保留你的 RAW 设置。
- 打开预览菜单，选“连续黑白”，退出菜单直接看画面；**不需要按快门，不需要先导出日志**。这一项只改预览，不改当前照片 LUT 选择。
- 移动相机，确认黑白画面持续更新，观察是否明显卡顿。请求成功不等于已有帧，更不等于实时像素验收成功。
- 再选“连续 S2 · 当前 LUT”，使用当前照片 LUT 和强度；“同步当前 LUT”只更新已启用的连续后端，不会偷偷启用。无当前选择走原样，有选择但表缺失或非法会报错，不假装已经同步。
- 选择新的照片 LUT 后，已有自动同步走可信 RAM 脚本，失败保留照片选择并明确报告。帧回调不读卡。
- “关闭 LUT 预览”为软停，后续帧走原厂路径。模块保留节点路由和恢复状态，直到相机进程真正退出；机身快照恢复可能保留同一进程。

如果画面仍是彩色，可进入原厂回放后再返回取景，让原厂自然重建取景链，再查看实际处理帧数。若仍未进入节点，保留状态以排查接入问题。操作超时则保留 loader/tracer 和驻留状态。

正常取景验证后，再由用户自愿进行普通拍摄测试，检查 RAW／RAW+JPEG 工作流及 JPEG 的既有 LUT 效果。不得自动拍照；本版本不更改 RAW Bayer。

## 控制与安全边界

连续操作使用已有 ABI4 普通 `apply --s2`，黑白100%，不带 `--probe-once`，默认 `--timing 0`，不自动启动收证或写诊断文件。保留私有 RAM job、有界等待、uncertain guard、source 身份、媒体与预览锁。独立 probe-only 包和其拒绝连续命令的策略保留。

VM 验证原厂 worker、ARM loader 和菜单逻辑，像素部分使用软件替身。旧版实机已观察到连续黑白；本次候选的硬件耗时、流畅度和拍摄兼容性需要在机身验收。
