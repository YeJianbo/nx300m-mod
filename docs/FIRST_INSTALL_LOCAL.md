# NX300M MOD 本机首次安装候选

此候选适用于已刷入 MFW 的 NX300M 1.15。电脑端不刷写固件。它从当前测试卡整理运行文件和两个基础风格；其中包含从卡上取得的原厂组合表，仅供本机测试，不作为公开发布包。

1. 相机关机，取出存储卡并连接电脑。将安装包解压到电脑，打开 NX300M-MOD.exe。
2. 选择存储卡，点击“首次安装 MOD”，核对盘符及卷号后确认。安装器不会格式化卡，也不会覆盖已有的 autoexec.sh 或 nx300m-mod 目录。
3. 等待写入和回读完成，安全弹出存储卡，插回相机开机，检查 MOD 菜单和滤镜。

安装中断时，保留界面列出的临时目录以及卡上已有文件，先检查后再处理。已有 MOD 的卡使用检查和升级功能。LUT 管理支持导入 sRGB 3D .cube；DCP 和 XMP 不支持直接导入。日志导出不会自动上传，分享前应检查内容。

工具中的“卸载 MOD”会把可识别的启动脚本和整个 MOD 目录移入卡上的 `nx300m-mod-backup-*` 目录，以便恢复；不会格式化卡或改写 MFW 固件。启动脚本与本工具不一致时会拒绝自动卸载，以免覆盖其他用途。

本候选尚未在一张没有 MOD 的卡上完成真实相机首次启动验证，不能视作正式发布版。无线连接和其他待完成扩展功能不因安装成功而视为已修复。
