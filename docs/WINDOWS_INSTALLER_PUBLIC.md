# NX300M MOD Windows 安装工具

适用于已刷入 MFW 的 NX300M 1.15。解压全部文件后运行 `NX300M-MOD.exe`，程序无需安装 Python。

## 首次安装

相机关机，取卡接入读卡器。选择存储卡后点击“安装 MOD 到存储卡”，核对盘符和卷号。写入并回读完成后，安全弹卡并放回相机开机。卡上已有 `autoexec.sh`、`nx300m-mod` 或 `nx300m-lens-debug` 时会停止，以便保留已有配置。

安装文件包含匹配的 ABI7 Session 预览后端。正常预览启用 Session 复用，逐帧计时与调用采样关闭，保留原厂 Reset、Still IQ 恢复和拍照仲裁。此次修正的首装组合尚未完成新卡实机复测。

完整包包含菜单和字库覆盖信息、LUT 引擎与 Still 加载器、ABI7 预览后端、开机恢复、NXConnect 相机端 HTTP/相册服务、Quick Share、Web 界面、手动镜头无线准入工具及开机配置。无线补丁只解除已有的无电子镜头入场限制，不自动创建热点或批准原厂手机授权。

首装、升级和独立 SD ZIP 共用同一份非 LUT 程序清单。菜单参考图内嵌于程序，中文字形使用相机原厂字体；无需另找字体或图片。模式拨盘锁定、动画和 Auto ISO 扩展尚未接通当前 SD 服务链的进程内加载，菜单按模块真实状态禁用；泛绿修复和 A/P 完整快门区间也不能当作现成功能。

## 已有 MOD 升级

选择卡后点击“检查升级”，通过后点击“升级 MOD”。更新完整非 LUT 程序、手动镜头无线资源、两个 Session 选择标记及运行清单，避免只更新菜单后保留旧引擎。原文件先备份到电脑的 `backups` 目录；照片、已有 LUT、镜头列表和参数保留。已有合法无线 profile 和运行标识也保留，未知程序版本拒绝覆盖。

## 原创 LUT

内置中性微调、硬调黑白、暖阳、晴蓝、柔彩、冷夜，共六款。配方由项目代码直接生成，不包含从 Lightroom、相机厂商或网友配置中提取的数据；生成配方及 LUT 数据按 CC0-1.0 提供。色彩效果未经硬件标定。

新装卡自动带上这些风格。已有卡升级后，打开“LUT 管理”，点击“添加内置风格”补充缺少的款式，已有同 ID 风格保留。可搜索、重命名，也可导入自己取得使用权的 sRGB 3D `.cube`。没有原厂组合表时使用现有直接表路径；卡上已有匹配组合表时，导入同时生成组合版本。DCP、XMP、1D shaper 和 Log LUT 不支持直接导入。

## 卸载和日志

“卸载 MOD”把本工具可识别的启动脚本、MOD 目录和无线补丁目录移到卡内 `nx300m-mod-backup-*`，可手动恢复；不改 MFW 固件或照片。遇到其他启动脚本时会停止，无法识别的镜头目录保留。

“导出日志”把本机安装记录、卡上 MOD 日志及手动镜头无线补丁的执行/读回日志保存成 ZIP，不会自动上传。分享前检查其中的设备、网络和路径信息。

## 本次验证范围

已核对 ABI7 运行文件与既有 ARM VM 验证所用文件一致，并执行隔离目录中的首装、旧首装修复、备份、卸载和 LUT 导入检查。模拟器和文件回读不能代替实机预览、拍照写卡和无线连接测试。本版本按预发布版提供，无线连接及修正后首装的实机性能仍待确认。

NX300 可能兼容但未验证，不保证适用。风险和第三方许可见 `RISKS_AND_RIGHTS.md`、`NOTICE.md` 和 `LICENSES`。包内不附 MFW 固件、三星系统字体、原厂 LUT 组合表或第三方滤镜。
