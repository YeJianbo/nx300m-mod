# v0.1.0-preview.5：LUT 工作台重构

Windows 客户端的 LUT 管理改为原生 Qt 工作台。现有卡内风格可在真实照片上分割对比，支持拖动分割线、缩放、平移和预览强度；管理端增加搜索、来源筛选、收藏、批量导入、拖放导入、文件夹导入、重命名、删除备份和导出 `.cube`。

本版同时重建首装与升级载荷，纳入当前 ABI7 Session 预览包装器、LUT 生命周期后端、最新 `nxui`、`mfw-panel-actions.sh` 和 `mfw-services.sh`。最新菜单与面板动作已通过私有 ARM VM 的下一启动开关、恢复、预览偏好及单次 Enter 导航回归；尚未完成新卡的物理首装复测。

导入支持标准 sRGB 3D `.cube`、`.vlt` 和 ZIP。批量导入会跳过重复项及 V-Log、CNED2、PORT、Classic Neo 等非 Standard 输入域，保留规范化源 LUT，并在电脑上保存导入前列表和完整本批备份。重命名同步 `looks.txt` 与 `look.json`；删除先复制完整风格目录，失败时恢复可恢复的卡内状态。

界面使用 PySide6/Qt，照片比较交互改编自 MIT 许可的 `hestela/lut-previewer`，LUT 资料库与批量导入结构参考 MIT 许可的 `OwenWhw/CUBE-to-XMP`。许可与署名随包保存在 `LICENSES`。

本版验证范围包括 Python 编译、Qt 离屏启动与两种窗口尺寸渲染、临时卡目录批量导入/去重/收藏/改名/删除备份、`.cube` 往返及打包 EXE 启动检查。读卡器、真实相机菜单和不同 Windows 缩放比例仍需实机复测。LUT 艺术文件不随公开包分发，作者再分发授权也需单独确认。
