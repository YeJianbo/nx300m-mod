# NX300M MOD v0.1.0-preview.2

修复 LUT 页面无法开启预览、列表上键跳出列表的问题，加大字体并减少菜单绘制与打开时的重复工作。旧版 preview.1 保留供回退。

## 本版变化

- 预览按钮使用经过校验的 RAM 服务，不再误执行 SD 卡上的脚本。
- 只读身份扫描使用可执行的正常启动器，修复诊断资源按只读权限暂存时无法启停预览的问题。
- 列表上下键逐项移动，只有第一项再按上才进入分组；分组中左右／转盘切组，下键或 OK 回列表。Fn 仍切换列表与微调。
- 主字体 28、辅助字体 22，调整按钮和百分比区域，分组焦点增加浅蓝边框。
- OK／保存统一为提交成功后回取景器；Fn 保存微调并回列表时保持面板打开。取消重复的“应用取景”按钮。
- 缓存字形、只上传变化图像区域；RAM 面板资源复用已校验的文件，进程身份扫描减少逐进程外部命令调用。

本版不修改 IPCS 硬件处理后端、原厂 Reset、IQ 恢复和拍照仲裁，不改变 RAW Bayer 数据。

## 下载与安装

- `nx300m-menu-upgrade-v0.1.0-preview.2.zip`：菜单与预览控制升级包，含 5 个运行文件及电脑端更新器。
- `nx300m-menu-source-v0.1.0-preview.2.zip`：对应源码和菜单构建使用的上游源文件。
- `NX300M-User-Guide.zh-CN.md`：中文使用指南。
- `NX300M-LUT-Panel.png`：本版 ARM/X11 模拟截图。
- `SHA256SUMS.txt`：附件完整性校验。

本包针对已有匹配 MFW RAM 服务、Still LUT 和 ABI7 Session 后端的 NX300M 1.15 环境，**不是首装包或刷机包**。NX300 可能兼容但尚未验证，不保证其他机型或固件版本适用。APK 沿用已有版本，本次未更新 Android App。

相机关机后取卡，将 ZIP 解压到电脑。电脑需要 Python 3.10 或更新版本，在解压目录执行；将 `H:/` 改为实际卡盘符：

```powershell
python update_card.py --card H:/
python update_card.py --card H:/ --apply
```

更新器先核对已有后端和控制文件版本，备份被替换文件，再写入并回读。保留照片、风格库、个人设置和 `autoexec.sh`。若版本不匹配，不要手工绕过检查。回退命令见包内指南。GitHub 自动生成的 Source code 不可直接当作 SD 运行包。

## 验证范围

ARM/X11 检查通过列表边界、分组按键／转盘、触摸预览按钮的 RAM 路由。Session 检查按实际只读权限部署诊断启动器，启停、黑白／彩色切换、拍照让路和异常恢复通过，Open／Close 为 218／218，剩余引用为 0。

模拟中的 ISP 硬件调用使用替身，只验证软件调用与资源生命周期，不能据此判断实体相机帧率或色彩。升级包另通过旧环境升级、全部替换文件回退、旧备份兼容，以及后端不匹配、未知控制文件和载荷损坏时零写入拒绝检查；当前测试卡只读预检通过。

新版菜单与控制文件已写开发测试卡并回读校验。实体 LCD 帧率、色彩一致性、RAW＋JPEG 连拍、休眠恢复以及新版完整保存耗时尚未完成验证。曝光与拨盘控制的菜单接线、手动镜头泛绿修复、EXIF 关联等未完成功能没有在本版宣称启用。

本项目非三星官方项目，测试版可能造成卡顿、拍摄中断或文件损坏，使用前备份。第三方代码和素材沿用原许可证；三星固件、字体、标定和第三方风格数据不随包分发。
