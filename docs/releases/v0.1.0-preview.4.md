# v0.1.0-preview.4：完整安装资源修补

补回首装包遗漏的手动镜头 Wi-Fi/分享准入工具、脚本和开机配置；统一首装、升级与独立 SD ZIP 的完整非 LUT 程序。菜单、LUT 引擎和 Still 加载器同步到当前测试卡候选，避免升级后回退旧程序。预览仍使用 ABI7 Session 后端，原厂 Reset、Still IQ、拍照仲裁、RAW 和 LCD DMA 不变。

- Windows ZIP：完整解压后运行 NX300M-MOD.exe，支持首次安装、完整升级、卸载、LUT 管理和日志导出。
- SD ZIP：用于已刷 MFW 的新卡；已有 MOD 请用 Windows 升级，保留配置和 LUT。
- 内置六款 CC0 原创 LUT，不包含第三方风格或原厂组合表；个人十款自制风格仍保留在用户测试卡，未一并公开分发。
- 卸载把已识别的 MOD 和无线补丁移入备份；日志导出包含无线补丁执行与读回日志。

最终 ZIP 完整性、实际打包 EXE 转换器、首装、旧发布包升级、配置保留、未知程序拒绝、日志导出及卸载八项离线检查通过。完整公开首装 109 个文件，RAM 运行清单 90 项。新包非 LUT 程序与当前卡逐项一致。

本版仍为预发布：手动镜头分享入口恢复及 LUT 关闭候选需实机复测。LUT 总开关与预览偏好尚未完全解耦，关闭再打开时不保留预览开关，是已确认待修项；本版未宣称已解决。原厂 RVF 401、图库删除误开菜单、菜单息屏、拍照闪色、冷启动表现和实际写卡性能也未全部关闭。详见 [问题清单](https://github.com/YeJianbo/nx300m-mod/blob/v0.1.0-preview.4/docs/ISSUES_2026-11-07.md)。

模式拨盘锁定、模式动画和 Auto ISO 等尚未完成当前 SD 链的原厂进程内接入，菜单依据真实加载状态禁用。A/P 完整快门范围与泛绿修复不作为现成功能发布。NX300 可能兼容但未验证，不保证适用。
