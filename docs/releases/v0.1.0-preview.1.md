## 菜单与 LUT

- 800×480 LUT 全屏面板，品牌分类、收藏、快速列表与八项微调；主菜单五个入口支持触摸和实体转盘。
- Fn 进入微调，再按 Fn 保存并回列表；OK／保存提交后不退出，MENU 返回并处理未保存修改。
- 新增“应用取景”：应用期间显示低频动画，后台提交成功才返回取景器；失败保留面板与草稿。无需半按快门确认提交，半按仍优先让路给原厂拍摄。
- 七项微调以零点为中心双向显示，强度独立；每款风格单独保存。
- 独立关闭 LUT 与关闭实时预览：关闭预览仍可拍带 LUT 的 JPEG，关闭 LUT 恢复原厂路径。
- 人像、风景、夜景三张参考图，点按切换、长按原图；参考图不是传感器实时画面。

已有 Still LUT 和 Session 预览后端保持原样。本次菜单更新不删除原厂 Reset、IQ 恢复，不调整硬件寄存器或 LUT 写表流程。

## 下载与安装

- `nx300m-menu-upgrade-v0.1.0-preview.1.zip`：**菜单升级包**，包含 ARM 菜单、电脑端更新工具、许可证与指南。
- `NX300M-User-Guide.zh-CN.md`：完整中文说明。
- `nx300m-menu-source-v0.1.0-preview.1.zip`：本版对应源码及菜单构建使用的上游源文件。
- `SHA256SUMS.txt`：附件完整性校验。
- GitHub 自动生成的 Source code：对应源码，不能当作 SD 运行包。

目前按 **NX300M 1.15＋已有匹配 MFW RAM 服务、Still LUT 与 ABI 7 Session 后端**开发验证。NX300 可能兼容，但尚未验证；不保证 NX300、NX500 或其他固件版本适用。不是 MFW 安装器或完整首装包，本次不提供 Android APK。更新器检查 18 个已有后端／资源文件，拒绝不匹配环境。

关机取卡，把 ZIP 解压到电脑。电脑需要 Python 3.10 或更新版本。在解压目录执行，将 `H:/` 改为实际卡盘符：

```powershell
python update_card.py --card H:/
python update_card.py --card H:/ --apply
```

自动备份旧菜单，写入后回读；保留照片、个人设置、原有风格库和 `autoexec.sh`。回退步骤见包内指南。已有卡的 LR/DCP 风格继续沿用，附件不包含这些数据、三星固件、字体或工厂标定。

## 已验证与待验证

本次 ARM/X11 模拟检查通过：应用结束前保留遮罩，成功退出，失败留在面板；保留滚轮导航、预览开关、长任务等待及保存交互。读卡器更新工具已检查只读预检、写入与回读、旧菜单恢复、后端不匹配拒绝，以及照片／设置／启动脚本保留。
