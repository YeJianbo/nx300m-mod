# v0.1.0-preview.6：LUT 批量分类与收藏同步

Windows 客户端的 LUT 工作台增加多选和批量分类。表格直接显示当前分类，可按 Ctrl/Shift 多选后一次归入同一分类，也可全选当前筛选结果并批量收藏。分类管理窗口显示每个大类包含的 LUT 数量，并保留新建、改名和删除操作。

收藏仍写入卡内 `nx300m-mod/.state/lut-favorites`，相机 LUT 面板读取同一文件；电脑端收藏或取消收藏后，重新打开相机 LUT 面板即可看到同步结果。

本次卡片目录从完整本地库中筛选 59 款常用 LUT，加 1 个原图基准项，分成 6 个大类。用户明确提供的 9 款 LUT 单独成组；其余不入机风格继续保留在本地 `lut-library`。173 个本地源 LUT 均保留可编辑 `.cube`，相机只接收编译后的 9³、10-bit、4380 字节原生表。

验证包括批量分类与收藏的孤立卡事务、Qt 离屏启动和界面渲染、Windows 安装器回归、分类数量与用户指定分组完整性、相机表尺寸/哈希/回读，以及本地到卡片的部署回滚。实体相机上的逐项切换与成像仍需实机复核。
