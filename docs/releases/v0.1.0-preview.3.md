# NX300M MOD v0.1.0-preview.3

本次新增 Windows 图形化安装工具，面向已刷 MFW 的 NX300M 1.15。

## 下载与安装

下载 `NX300M-MOD-Windows-v0.1.0-preview.3.zip`，完整解压后运行 `NX300M-MOD.exe`。首次使用选择存储卡并点击“安装 MOD 到存储卡”；已有 MOD 的卡选择“检查升级”，通过后点击“升级 MOD”。包内提供中文说明，不需要安装 Python。

原首装候选遗漏 ABI7 Session 选择标记，可能回落到旧 ABI4 预览路径，造成预览体验退回。本版补回选择标记和运行清单，并对首装、升级及回读加入配套后端检查。已有错误首装卡可以直接升级修复。保留原厂 Reset、Still IQ 恢复和拍照仲裁。

## LUT 与管理

内置六款独立配方生成的原创风格：中性微调、硬调黑白、暖阳、晴蓝、柔彩、冷夜。配方和 LUT 数据按 CC0-1.0 提供，不包含从 Lightroom、厂商或网友滤镜中提取的数据。

LUT 管理支持搜索、重命名、导入 sRGB 3D `.cube`，以及给已有卡“添加内置风格”。已有同 ID 风格保留，导入或添加不会切换当前风格。单独的原创 LUT 包附有 `.cube` 母表及原生 `.d4lut`。

## 卸载与排错

新增可恢复卸载：把本工具可识别的启动脚本和 MOD 目录移至卡内备份目录，保留照片和 MFW。更新前文件备份在电脑的 `backups`；工具可导出本机和相机运行日志，不自动上传。

## 验证与已知问题

构建通过；隔离目录检查覆盖首次安装、原首装遗漏标记的修复、备份、卸载、原创风格补充和无原厂组合表时的 LUT 导入。ABI7 后端与既有 ARM VM 验证所用文件一致。

这次修正后的完整首装包仍待新卡实机复测，不能把文件回读等同于帧率、拍照写卡或色彩校准通过。无线连接仍有未关闭的实机问题。NX300 可能兼容但未验证，不保证适用其他机型或固件。

公开包不附 MFW 固件、三星系统字体、原厂 LUT 组合表、Adobe 或第三方滤镜。第三方代码与素材沿用各自许可证，完整对应源码随同发布。风险和许可见包内说明。
