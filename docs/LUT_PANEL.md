# LUT 面板

LUT 面板为 800×480 全屏布局，左侧参考图，右侧切换风格列表与八行微调。主菜单为 800×264 横向面板；功能子页复用窗口，无转场动画。

主菜单有五个入口：LUT 滤镜、镜头管理、曝光增强、手机连接、系统设置。转盘或左右选择，OK 或下键进入，MENU 返回；各功能列表也支持转盘选择，转动本身不执行操作。调试位于系统设置。首页从缓存显示 LUT 预览、拨盘和镜头状态。未接入或未验证的功能显示不可用，不执行硬件写入。

- 顶部分类直接筛选风格，最多同时显示六类，可左右翻页并记住最后分类。列表上下键移动风格，只有第一项再按上才进入分类导航，当前分类出现浅蓝边框；左右键或主拨轮切分类，下键或 OK 回列表。分类内按 OK 只回列表，不提交风格。
- Fn（原厂 `XF86HomePage`）进入微调；再次按 Fn 保存调整并回到列表，面板不退出。触屏的“微调／列表”按钮执行相同操作。Fn 长按不重复切页。
- 列表中上下键、左右键、主拨轮或触摸选择风格；OK／保存提交后回到取景器，浏览本身不提交。微调时上下选择参数，左右或主拨轮（`XF86ScrollUp/Down`）调整数值。只在当前面板内接收这些事件。
- 亮度、对比度、饱和度、色温、色调、阴影、高光范围为 −10～+10；强度为 0～100%。色调对应绿—洋红方向；色温、色调均为 LUT 输出调整，不修改原厂白平衡。
- 每个参数一行，支持触摸滑动；七项有符号参数从零点向两侧填充，强度单向填充。黑白表仅禁用无效的饱和度，仍可用色温和色调给黑白调色。
- 保存或 OK 提交当前风格和微调，成功后退出到取景器；Fn 从微调保存并回列表时保持面板打开。MENU／顶部返回保持返回逻辑，有草稿时选择保存、放弃或继续编辑；半按快门立即让路。提交中不接收后续修改，失败保留草稿以便重试。配置保存与硬件像素生效分别表述。
- 顶部合并为“返回”和“保存”，不再提供重复的“应用取景”。保存也会提交未修改的已保存风格。应用期间显示简短动画，不重算参考图，空闲时不刷新；不依赖半按快门确认，也不增加固定等待。后台成功代表控制事务完成，不能据此断言 LCD 已显示第一帧新效果。
- “重置当前”只清零当前风格的七项微调并恢复 100% 强度，再保存生效。
- 顶部独立红色“关闭 LUT”恢复原厂路径，不参与列表轮换。
- 收藏存于卡上 `.state/lut-favorites`。短按 Custom 打开 LUT 面板，在列表内选择风格；长按打开 MOD 主菜单。
- 面板在当前分类内缓存可见成员；只有切换分类或修改收藏才重建索引。短按 Custom 成功切换后的提示面板缩短为 650 ms，避免额外全屏面板长时间遮挡取景。

预置人像、风景、夜景三张参考图；点按换图，长按显示原图，松开恢复效果。图像来源与许可证随包提供在 `REFERENCE_IMAGES.txt`。仅在风格、微调或参考图变化时生成小图；没有读取传感器画面。软件采用候选 RGB 坐标和三线性插值，不能作为硬件插值、原生色彩域或 LCD 色彩已标定的证据。

微调在原生 LUT 输出码值域中执行：先依据加权亮度调整亮度、对比度、阴影和高光，再调整相对亮度的饱和度，最后加零亮度的冷暖／绿洋红偏移，统一裁剪并四舍五入到 10-bit。这里的冷暖不修改原厂白平衡，亮度不等于曝光 EV。零微调直接复制原表，保证字节一致。

确认时生成直接表和原厂 3D 组合表两种缓存，保存在 `looks/nx-tune-<key>/`；RAM Hook、IPCS Reset、IQ 恢复以及逐帧处理流程均保持现有实现。缓存键绑定源表和微调，命中时仍比较内容。相同缓存不重复写入；原风格表不覆盖。每款风格的微调和强度存于 `.state/lut-tune-<id>`。

开关预览成功后保存 `.state/lut-preview`。MFW 服务就绪后运行一次有限的 `lut-boot.sh`：等待唯一原厂进程及 IQ/UDD 库，使用原有引擎恢复卡上选择，再按保存开关请求预览。不会强制发送取景重建通知；实际 LCD 首帧时机仍需实机确认。错误写入 RAM `state/lut-boot.log`，不会循环重新注入。

验证记录位于 `outputs/review/menu-toggle-width/` 和 `outputs/performance/lut-menu-entry/`。ARM 软件检查覆盖缓存、持久化、默认值、损坏拒绝和面板交互；SmartFilter VM 使用原厂库和模拟 MMIO。实体相机的开机首帧、触摸手感及 LCD/JPEG 色彩一致性不由这些检查证明。
