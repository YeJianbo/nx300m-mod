# NX300M LUT 切换检查

本轮检查同一次选择能否同时更新取景和 JPEG。Session 流畅预览保留，普通使用不启动性能采样。

默认目录为 23 款加「关」：富士 CC／Astia／Eterna／NC／NN，奥林巴斯 Vivid／Muted／Chrome，宾得 Natural／Bright／反转片／SATOBI／银盐漂白／Gold，自制日光／海盐晴蓝／薄荷青绿／奶油暖光／电影青橙／日出淡彩，以及 GR Neg／GR Pos、Hard Mono。其余源文件保留，启用清单为 `looks/catalog.json`。当前目录包为 `outputs/looks/lightroom-import/on-camera-test/nx300m-lut-color-test.zip`。

1. 装测试卡开机，使用 P／A／S／M，关闭原厂智能滤镜。
2. 短按 Custom 打开 LUT 面板，选 Hard Mono、100%，保留并关闭。
3. 长按 Custom，选择「开启取景预览 · 当前 LUT」，退出面板，先不拍照、不进回放，检查黑白是否直接出现。ABI7 补接原厂停流完成及内存匹配恢复，首次接入须实体复测。
4. 拍一张照片，检查取景和回放的 JPEG 都是黑白。
5. 短按 Custom，切 GR Pos 或富士 CC，保留并关闭，先查看取景，再拍照；确认切换不再依赖相册或第一张照片。
6. 再切 Hard Mono 拍一张，检查没有残留上一款效果。
7. 在主菜单选「关闭取景预览 · 照片保留」，确认取景恢复原色，JPEG 继续带当前 LUT。换另一款风格再拍，取景应保持原厂，照片使用新风格。需要时重新开启预览。
8. 选择列表首项「关」，确认取景恢复原色，再拍一张原厂 JPEG。
   此项停止预览处理、释放 Session，并撤回成片的两个 Hook；关闭选择会保存到卡。
   再次打开列表不应自动加载成片模块。选回 GR Pos 时按需重新加载，
   要恢复取景效果，再选择「开启取景预览 · 当前 LUT」。

打开面板保持预览运行。诊断统一位于「调试与诊断」；其中「关闭预览并保存诊断」在停止后额外导出日志，日常使用选择主菜单的普通关闭。
菜单中的 Hard Mono 与成片使用同一个选择，不再提供独立的黑白预览按钮。
T1–T5 和 A/B 副本从菜单移除，彩色使用正式风格。
选择「关」后先停止处理和释放 Session，再由原厂控制线程移除 S2 预览节点；拍照期间延后执行。RAM 映射保留至相机进程退出。

若出现会话不可应用、切换未生效或预览与照片不同，记下当时选择，正常关机后把卡接回电脑。日志在 `nx300m-mod/logs/fn-key.log`，无需相机 Shell。

本轮修正首次开启和关闭时停在 state20 的恢复分支，并在异步停流完成后唤醒控制线程。已有预览中的风格切换只更新 RAM 参数，不重复重建节点；稳定取景时省去不必要的原厂状态查询。实体复测前，不将模拟中的恢复成功视为 LCD 已验证。
