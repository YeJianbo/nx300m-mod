# 更新日志：0.9.0 → 0.15.0

> 适用于 `NXConnect-0.15.0.apk`（versionCode 29）

---

## 新增功能

**遥控按键面板（30 个键，可展开）**
分三组：曝光参数（ISO / 白平衡 / 测光 / 对焦模式 / 对焦触发 / 景深预览）、
导航与转盘（方向键 / OK / MENU / Fn / 播放 / 删除 / 主副转盘 / 滚轮 / 录制）、
拍摄模式与驱动（P/A/S/M / 智能 / 场景 / SAS / 自定义 1-2 / 单张 / 连拍 / 高速连拍 / 定时 / 包围）。

**「相机屏幕」镜像**
把相机自己的屏幕投到手机上，**可以直接操作相机菜单改曝光参数**，
并同时显示取景画面 —— 构图与参数面板一起看得到。

**空状态插图**
相册没有照片时显示插图与提示，不再是一行灰字。

**「曝光补偿」与「AE 锁定」改为按住生效**
用 keydown/keyup 实现，配合转盘调节才和机身手感一致（单击会立刻松开，转盘无效）。

**B 门时可选自动关相机屏幕**，省电并避免漏光。

**遥控期间手机屏幕常亮**，长曝光时能盯着计时。

## 修复

| 问题 | 说明 |
|---|---|
| **取景高清画质偏慢** | `HttpURLConnection` 默认缓冲约 8 KB，518 KB 的一帧要读 63 次。改成 64 KB 分块，实测网络耗时从 **288 ms 降到约 199 ms** |
| **遥控页按键全部发灰、像被禁用** | Material 3 填充按钮的默认文字色是半透明灰，直接用在"深色底 + 仅描边"的按钮上观感就是禁用。改为显式状态列表（正常亮色 / 按下变暗 / 禁用才灰） |
| **顶部三个切换按钮高矮不一** | 长文字折成两行把行撑高。改为定高 + 强制单行 + 省略号 |
| **顶栏被手机状态栏挡住** | 四个页面（连接 / 相册 / 遥控 / 看图）统一改为由根布局消费系统 inset，不再依赖各个视图自己解释 padding |
| **状态卡片三行文字被裁切** | 背景圆角是 100 dp，三行高度约 48 dp 时两侧被挤成尖角并切字。改为 10 dp |
| **叠加模式下帧率偏低**（2.5 → 4.1 fps） | 解除了 400 ms 的请求间隔限制（实测证明该限制没有依据） |

## 说明

- **实时取景与相机屏幕镜像可以同时开**，但两路流共用相机的处理能力。
  相机端 HTTP 的吞吐上限实测约 **4.5~5 fps**，所以两者同开时各自的更新率会相应降低。
- **镜像是"读屏幕"而不是"读参数"**：相机端不提供读取曝光参数的接口（实测无
  `vconf`、无参数查询端点、`capdtm` 只能读 1 个参数），
  所以当前 ISO / 快门 / 光圈等数值**只能通过「相机屏幕」看到**，无法在 App 内独立显示。
- 相机屏幕的变化帧需要整屏重绘，**一次约 0.7 秒**，这是相机端的物理上限。
